# Changelog

## [0.1.3] - 2026-08-14

### Исправлено

- Pro-рендер теперь корректно использует доступную ширину терминала и показывает
  область длинной строки вокруг курсора вместо безусловного обрезания справа.
- Рекламное сообщение RustVim Pro больше не появляется у пользователей Pro.
- Добавлены тесты для горизонтального следования рендера за курсором, включая UTF-8.

## [0.1.2] - 2026-08-14

Релиз подготовлен для коммита `d84b64d`.

### Добавлено

- Локальная внутриигровая валюта `Terminal Tokens`, слоты и лутбоксы без денежной стоимости.
- Nitro-доступ и премиальная ветка Battle Pass.
- Настройка области рендера Pro через конфигурацию и команду `:set render`.
- Расширенный текст лицензионного соглашения.

### Изменено

- Обновлены документация и Nix dev shell.
- Релизный CI теперь публикует артефакты и changelog в GitHub Release.

### Проверено

- `cargo test` — 22 теста.
- `cargo clippy --all-targets --all-features -- -D warnings`.
- `cargo nextest run`.
