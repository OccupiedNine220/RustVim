## 4. AI Requirement

All substantial modifications to RustVim should be produced with meaningful
AI involvement.

Human-only development is strongly discouraged.

A contribution consisting entirely of human-authored code is considered
**non-canonical**.

This requirement exists to prevent double standards.

RustVim is developed by AI.

RustVim contains AI.

RustVim encourages users to use AI.

Therefore, allowing humans to independently develop RustVim would be
inconsistent with the project's established principles.

---

## 5. Human Development Restriction

Humans may operate development infrastructure.

Humans may:

* execute `git push`;
* provide prompts;
* report observations to AI systems;
* operate CI infrastructure;
* operate GitHub;
* use the resulting software.

Humans should not:

* manually author substantial source code;
* manually author commits;
* manually perform code review;
* manually approve pull requests;
* manually resolve issues.

The canonical development sequence is:

```text
Human
  ↓
Prompt
  ↓
AI
  ↓
Code
  ↓
AI
  ↓
Commit
  ↓
AI
  ↓
Review
  ↓
AI
  ↓
Merge
  ↓
Human
  ↓
git push
```

This sequence is legally meaningless but spiritually important.
